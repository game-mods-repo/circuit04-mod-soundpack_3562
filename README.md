## Как установить в игре
1. Запустите игру **Circuit 04**.
2. Перейдите в **Главное меню -> «Моды» -> вкладка «Каталог»**.
3. Найдите мод **Пользовательский звуковой пак** и нажмите кнопку **«Установить»**.
4. Включите мод в списке активных модификаций.
